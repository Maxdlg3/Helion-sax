Pourquoi pas de tarif fixe ?

Un mariage dans le 16e sur 1h, un cocktail corporate de 3h au Marais, une soirée privée sur un rooftop avec DJ : tout cela ne peut pas avoir le même prix. Hélion préfère un devis sur mesure — vous payez ce qui correspond à votre événement.

Les facteurs qui déterminent votre devis

1. Durée

1h ou 4h avec plusieurs sets — c'est le facteur n°1.

2. Type d'événement

Mariage, cocktail corporate, soirée privée, défilé.

3. Lieu & déplacement

Paris, IDF, région, international.

4. Format

Solo acoustique, sax + matériel, duo DJ + sax, formation musiciens.

5. Interventions

Cérémonie + vin d'honneur + soirée = forfait plus avantageux.

6. Période

Haute saison (mai-oct, samedis), jours fériés.
